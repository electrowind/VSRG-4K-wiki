    常规 / 常规键型 / rice / RC / regular

    狭义指仅由米构成的键型。

    1. 叠键 / 叠 / jackhammer / jack / chordjack / CJ

      相邻行之间允许按键重叠的谱面。
      常见分度为 16 分。
      重灾区其一，大中小叠键之间没有明确区分，这个问题本质是沙堆悖论，轻切和乱、LN，HB 和 RC 的区分也同理，无法给出一个度量来区分这些键型。

    *截图自沙堆悖论_百度百科。

      除部分非常模糊的谱面，沙堆悖论并不影响我们分类绝大多数谱面。

    4K 系音游完全入门到精通指南 #3 全键型详解 提供了一种分类方法。

    1.1 小叠 / low chordjack / minijack

    1.2 中叠 / mid chordjack

      中叠是近年才出现的键型用以归类中等密度的叠键，在此仅做收录。

    1.3 速叠 / speedjack / jackspeed

      有说法是切指较多的叠；Etterna 社区中指密度较小的叠，和大叠相反。

    1.4 大叠 / high chordjack / chordjack

    1.5 满叠 / dense chordjack

      密度很高的大叠，通常仅由四押和三押构成；部分人认为类似Break[Smash] by beary605 的 4342 和 4242 排列也是满叠。
      BPM 较高时可以用 VC / vibro control 的技巧打出较高准度。

    1.6 扣洞叠

      密度极高的大叠，通常只有少量三押，其余均为四押。

    1.7 纵叠 / anchor jack

      有大量纵连的叠键。

    1.8 四押切 / quadstream

      常见四押切是在切键的每拍或每两拍出现一个四押，这一定会导致产生子弹，所以四押切其实是叠。

    1.9 双押叠 / 切叠[1] / jumpjack

      全是双押的叠。

    [1]有争议，圈内最常见的键型划分图（见附录 3）将 jumpjack 和切叠划等号。

    1.10 三押叠 / handjack / triple jack

      全是三押的叠。

    1.11 四押叠 / 四押纵 / quadjack

      全是四押的叠。
      一般放在其他键型的衔接处。

    2. 乱键 / 乱 / 大乱 / stream / speed / dumpstream

      相邻行之间不存在重叠的谱面，含有极少量或不含双押和三押。
      常见分度为 32 分。
      脚排列、古典排列、现代排列由锚键的多少区分，其中脚排列＞现代排列＞古典排列。
      DDMythical 之后 speed 可代指乱键。

    2.1 脚排列

      一四列固定配色[2]，二三列配色无明显要求；谱面中锚键出现频率高， 且多集中于两侧；脚排列一般仅包含单乱。如图 2-27 中一四列存在大量锚键。

      没有多押的乱键。

    3. 切换 / 切键 / 切 / stamina / stream / ST

    切换_哔哩哔哩 bilibili_OSUMANIA   相邻行之间不存在重叠的谱面，含有较大量的双押和三押。   常见分度为 16 分。   英文中并没有完美对应切换的词，DDMythical 之后 stamina 可代指切换，Malody 侧则直接将切换称为 stream。Interlude侧将切换称为 Chordstream，但该词在 7K 社区有其他含义。

    3.1 双押切 / jumpstream / JS

      没有三押的切换谱面，常用 2121，2111 来粗略表示排列，这里的数字代表每行的键数。

    3.2 三押切 / handstream / HS

      含有大量三押的切换谱面，常用 3131，3111 来粗略表示排列；注意，允许出现双押甚至允许双押数量大于三押。

    3.3 轻切 / 稀切 / 小切 / light jumpstream / lighthandstream / LJS / DJS

      密度较小的切换。   轻切和小切一般指 LJS。

    3.4 中切

      中等密度的切换，介于轻切和满切之间。 2.1.2.3.5 满切 / 大切 / 密切 / dense jumpstream / densehandstream / DJS / DHS   密度较大的切换。

    4. 技巧 / 技 / technical / tech

    关于 tech 的一些理解 - 哔哩哔哩   无法归类于切换、叠键、乱键的常规键型统称为技巧。

    4.1 乱技 / speedy tech

      排列更倾向于切换或乱键。

    4.2 叠技 / jacky tech

      排列更倾向于叠键。

    4.3 混合技巧 / mixed tech

      切换难度和叠键排列分布比较的技巧，有时是同时含有大段叠键、切换以及技巧的谱面。

    4.4 断切 / 间断切 / broken jumpstream / broken handstream / 碎切

      未填充所有行的切换。

    4.5 断叠 / 间断叠 / jack control

      未填充所有行的叠键。

    4.6 多级乱 / polystream

      同时使用多种分度的乱键。
