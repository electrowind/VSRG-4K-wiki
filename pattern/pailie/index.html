    排列和写谱技巧

      键型是由大量的排列构成的，这些排列有重复的，也有不同的。

    1. 子弹 / 短纵 / 小纵 / minijack

      在一定分度的谱面里出现小间距的连续单键。

    *图中蓝色的键表示被选中的键，下同。

    2.锚键 / 锚 / anchor

      同一列中连续出现的等间距单键，常见于切换。
      纵和锚在叠键的常见分度[2]是 16 分，在切换的常见分度是 8 分。

    [2]分度=N分音符×4；对于 osu，谱面编辑右上角即为节拍细分，节拍线对上 note 即为节拍细分 / 音符时值 / beatsnap devisor / snap / 拍，N 分音符=1÷节拍细分。相同的排列，分度越高，则密度越高，越紧凑。

    3. 纵连 / 纵 / longjack

      同一列中连续出现的等间距单键，常见于叠键；可以是单押或者多押；有时不要求等距。

    4.滚动 / roll

      向同一方向排列的等间距单键，不限方向，只能是四个一组。   英文名 roll 的使用频率远高于中文名。

    5. 梯子 / rail / ladder

      向同一方向排列的单键，不限方向。

    6. 钩子 / 楼梯 / staircase

      向同一方向排列的单键突然向相反方向排列并形成拐角。

    7. 交互 / trill

      两列等间距的单键，形成错位的纵连。

    7.1. 单手交互 / one hand trill

      在同一只手的交互。

    7.2. 双手交互 / two hand trill

      在两只手的交互。

    8. 对拍 / jumptrill

      12 / 34 轨交替排列的等间距双押，有时也称之为一种打法，例如高速对切和高速 roll 都能用对拍技巧打出较高准度。

    9. 对切 / splittrill / jumptrill

      13 / 24 轨或 14 / 23 轨交替排列的等间距双押。有时候不区分 jumptrill 和 spittrill。

    10. 散点 / split rail

      无规律的一组单键。

    11. Grace / flam

      以极小间距排列的一组单键。

    12. 盾 / shield

      一个单键后紧跟一根较长的面条。
      盾这个称呼有时包括反盾；也可代含有大量盾和反盾的键型。

    13. 反盾 / reverse shield

      一根较长的面条后紧跟一个单键。

    14. Burst / 爆发

      相比高潮段，更紧凑的排列，且长度非常短。

    15. 塞 / 塞爆 / dump / 荡谱 / 荡

      没有采音的地方强行放置音符，是一种写谱技巧。
      在定轨下落式音游以外的社区较少见，容易引发争论，笔者认为任何写谱技巧都是服务于谱面的，如果使用得当，能够很好的表达谱面情感。

    16. Accurate

      严格按照采音放置音符，是一种写谱技巧。
      常见于 osu 上架 / ranked 或者 Malody 上架 / stable 谱面。

    17. 面点

      一根较长面周围有非常多米的排列。常见于远古谱面。
