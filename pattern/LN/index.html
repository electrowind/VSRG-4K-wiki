    面条 / 面 / long note / LN

      面条比例极高的键型。
      详细讲解可参考[osu!mania4k]LN 基础图池键型介绍。

    1. 反键 / inverse / LN wall / full LN

      同一列只留下少量，并且相同分度的空间，其余全填充面条的键型。

    2. 放手 / release

      面条的结尾长度不一致或无规律，考验放手时机。

    3. 面技 / 技巧面 / tech LN / TL

      技巧与面条的结合。

    4. 密度 / density / DE

      几乎所有时候都有一根较长的面条的键型。
      较常用英文名。

    5. Wildcard / WC

      含有多种面条排列的键型，同时考察面和米。

    5.1 Speedy WC

      类似多级乱的面图，手感接近乱键。

    5.2 Jacky WC

      类似叠键的面图，常含有大量盾和反盾，手感接近叠键。

    6. 协调 / coordination / CO

      几乎所有时候都有一到两根较长的面条，并且分布在两只手。

    混合 / hybrid / HB

      混合米和面的键型。
      面的键型很多其实都可以归类于混合，无法简单区分 RC、LN 和 HB，故不再单开页面说明。
