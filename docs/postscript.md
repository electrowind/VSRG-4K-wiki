# 后记

&emsp;&emsp;现学的 word，原本想学学[《学术论文编写规则》（GB / T 7713.2—2022）](https://ist.cpu.edu.cn/ec/a0/c12785a191648/page.htm)实施，发现这种标题不够醒目，于是参考其他人的排版，自创了这种排版，我知道很垃圾别骂了（

&emsp;&emsp;大概是在基本框架完成的时候写的，前前后后花了有一个多月的时间，几乎把所有空余时间用来写这个，锁妖塔更新也停了。在这一个月之中有的数据更新我也得重新写，尽量做到在 2025 / 10 / 23 这一刻，本文的是具有时效性的。原本是只想写一些常见名词的意义，但后来想了想还是写了点 osu、Malody、StepMania 的历史，原先也不准备提供建议，后来还是写了点推荐的谱师和图包。参考了很多文章，完全抄袭，没有一点原创（

&emsp;&emsp;比较难受的应该是很多资料都查不到，有的是一些玩家退坑顺带把 osu 论坛，油管或者推特的资料全删了，有的是太古老又无从查证。

&emsp;&emsp;本文没办法收录下落式音游的所有事件、人物、专业名词，一是笔者能力有限，二是本文的目的不是作为 wiki 那种百科全书式的教程，顶多算是个引导性质的文章，具体如何提升实力，如何制作优秀谱面，如何享受游戏，如何服务于社区还得靠读者自行体会。

&emsp;&emsp;本文重复了多次 wiki，希望读者真的会去查 [wiki](https://osu.ppy.sh/wiki/zh/Main_page)。

&emsp;&emsp;感觉没什么写 Q &amp; A 的必要。。。吧。
