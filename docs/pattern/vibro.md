# 秒杀 / 歪脖 / vibro / V / manipulating elbowjack<sup>*</sup>
&emsp;&emsp;快速抖动点击的一种技巧，也指一些需要使用这种技巧的谱面。<br />
&emsp;&emsp;有时指可以用糊全押谱的方式打的谱面，此时对是否使用该技巧无要求。<br />
&emsp;&emsp;[Conservation 的 Vibro(秒杀)基础教学 [粉丝投稿字幕]_哔哩哔哩_bilibili](https://www.bilibili.com/video/BV1bW411r7Dt/)
## 1 协调 / control / VC
&emsp;&emsp;考察多指协调能力的秒杀键型。
## 2 爆发 / dense / speed<sup>*</sup>
&emsp;&emsp;较高 BPM 的秒杀，但持续时间较短。
## 3 耐力 / stamina / ST
&emsp;&emsp;较长的高潮段，考察稳定性和耐力。
<div style="text-align: right;color: lightgray;"><i><sup>*</sup>均为远古名称，无人使用。 </i></div>
