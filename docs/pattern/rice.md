# 常规 / 常规键型 / rice / RC / regular
狭义指仅由米构成的键型。

## 1. 叠键 / 叠 / jackhammer / jack / chordjack / CJ
&emsp;&emsp;**相邻行之间允许按键重叠的谱面。**<br />
&emsp;&emsp;常见分度为 16 分。<br />
&emsp;&emsp;重灾区其一，大中小叠键之间没有明确区分，这个问题本质是沙堆悖论，轻切和乱、LN，HB 和 RC 的区分也同理，无法给出一个度量来区分这些键型。

## 2. 乱键 / 乱 / 大乱 / stream / speed / dumpstream
&emsp;&emsp;相邻行之间**不存在重叠**的谱面，含有极少量或不含双押和三押。<br />
&emsp;&emsp;常见分度为 32 分。<br />
&emsp;&emsp;脚排列、古典排列、现代排列由锚键的多少区分，其中脚排列＞现代排列＞古典排列。<br />
&emsp;&emsp;DDMythical 之后 speed 可代指乱键。

## 3. 切换 / 切键 / 切 / stamina / stream / ST
[切换_哔哩哔哩 bilibili_OSUMANIA](https://www.bilibili.com/video/BV1Vf4y1F7VS/)
&emsp;&emsp;相邻行之间**不存在重叠**的谱面，含有较大量的双押和三押。
&emsp;&emsp;常见分度为 16 分。
&emsp;&emsp;英文中并没有完美对应切换的词，DDMythical 之后 stamina 可代指切换，Malody 侧则直接将切换称为 stream。Interlude侧将切换称为 Chordstream，但该词在 7K 社区有其他含义。

### 3.1 双押切 / jumpstream / JS
&emsp;&emsp;没有三押的切换谱面，常用 2121，2111 来粗略表示排列，这里的数字代表每行的键数。
### 3.2 三押切 / handstream / HS
&emsp;&emsp;含有大量三押的切换谱面，常用 3131，3111 来粗略表示排列；注意，允许出现双押甚至允许双押数量大于三押。
