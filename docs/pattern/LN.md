# 面条 / 面 / long note / LN

&emsp;&emsp;面条比例极高的键型。<br />
&emsp;&emsp;详细讲解可参考[[osu!mania4k]LN 基础图池键型介绍](https://www.bilibili.com/video/BV152421N7F9)。

## 1. 反键 / inverse / LN wall / full LN
&emsp;&emsp;同一列只留下少量，并且相同分度的空间，其余**全填充面条**的键型。
## 2. 放手 / release
&emsp;&emsp;面条的结尾长度不一致或无规律，考验放手时机。

## 5. Wildcard / WC
&emsp;&emsp;含有多种面条排列的键型，同时考察面和米。
### 5.1 Speedy WC
&emsp;&emsp;类似多级乱的面图，**手感接近乱键**。
### 5.2 Jacky WC
&emsp;&emsp;类似叠键的面图，常含有大量盾和反盾，**手感接近叠键**。

## 混合 / hybrid / HB
&emsp;&emsp;混合米和面的键型。<br />
&emsp;&emsp;面的键型很多其实都可以归类于混合，**无法简单区分 RC、LN 和 HB**，故不再单开页面说明。
