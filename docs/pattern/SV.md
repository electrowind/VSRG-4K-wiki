# 变速 / SV / speed variation
&emsp;&emsp;下落速度有改变的谱面。<br />
&emsp;&emsp;谱面演示见[传统下落式音游键型与玩法详解 【精准空降到 04:04】](https://www.bilibili.com/video/BV1Zj411d78M/?share_source=copy_web&vd_source=afeecb904ccf1e1b87279ee2d2f945cc&t=244)。
## 1. Bump
&emsp;&emsp;下落速度快速改变，然后又快速恢复正常。
## 2. Fastjam
&emsp;&emsp;下落速度变得很高。
## 3. Slowjam
&emsp;&emsp;下落速度变得很低。
## 4. Stop
&emsp;&emsp;下落速度变为零。
## 5. Negative
&emsp;&emsp;下落速度变为负数，note 向上（上落式模式相反）滚动。
## 6. Teleport
&emsp;&emsp;Note 快速移动并停止，视觉上就像传送或掉帧一样。
## 7. BPM nomalisation
&emsp;&emsp;将下落速度矫正为原先的下落速度。
