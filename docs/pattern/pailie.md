# 排列和写谱技巧
&emsp;&emsp;键型是由大量的排列构成的，这些排列有重复的，也有不同的。

## 2.锚键 / 锚 / anchor
&emsp;&emsp;同一列中连续出现的**等间距**单键，常见于切换。
<br />
&emsp;&emsp;纵和锚在叠键的常见分度<sup>[2]</sup>是 16 分，在切换的常见分度是 8 分。
<div style="text-align: right;color: lightgray;"><i><sup>[2]</sup>分度=N分音符×4；对于 osu，谱面编辑右上角即为节拍细分，节拍线对上 note 即为节拍细分 / 音符时值 / beatsnap devisor / snap / 拍，N 分音符=1÷节拍细分。相同的排列，分度越高，则密度越高，越紧凑。</i></div>

## 8. 对拍 / jumptrill
&emsp;&emsp;12 / 34 轨交替排列的**等间距双押**，有时也称之为一种打法，例如高速对切和高速 roll 都能用对拍技巧打出较高准度。

## 12. 盾 / shield 
&emsp;&emsp;一个单键后紧跟一根较长的面条。<br />
&emsp;&emsp;盾这个称呼有时包括反盾；也可代含有大量盾和反盾的键型。

## 13. 反盾 / reverse shield 
&emsp;&emsp;一根较长的面条后紧跟一个单键。

## 15. 塞 / 塞爆 / dump / 荡谱 / 荡
&emsp;&emsp;没有采音的地方强行放置音符，是一种写谱技巧。<br />
&emsp;&emsp;在定轨下落式音游以外的社区较少见，容易引发争论，笔者认为任何写谱技巧都是服务于谱面的，如果使用得当，能够很好的表达谱面情感。

## 16. Accurate
&emsp;&emsp;严格按照采音放置音符，是一种写谱技巧。<br />
&emsp;&emsp;常见于 osu 上架 / ranked 或者 Malody 上架 / stable 谱面。
