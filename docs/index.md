**注意事项：**

2. 如有摘录部分禁止转载，联系我立即删除；本文不对任何言论负责。 
3. 可使用搜索功能快速查找关键词。       
4. 游戏内出现的名词如 OD，HP，PP 等都可以去 [wiki](https://osu.ppy.sh/wiki/zh/Main_page) 查找。 
5. 如果没有特别说明，默认 osu 使用的版本是 stable，Malody 使用的版本是 4.3.7。  
6. 音游名词应当和语言文化一样，每个时期、每个人对于同一词语含义的解释不尽相同，包括本文，本文的任何言也不应被当做铁律。 
7. 本文不会提及任何 mania 的负面人物，但这不代表不存在负面人物或本文提及的玩家没有做一些现在看来有些不妥的事，读者注意甄别。    

---

希望读者能够做到，看见一标题为“[Malody]XXXXXX（stamina alpha+++）”的视频，能够友善评论，如“大神啊”，“无敌”，从*两害取其轻*的角度来说，甚至卖弱都可以，如“我的一辈子”，“我什么时候这么强。。。”；    **不要**出现如“Stamina 不是切，而是耐力”，“Stamina 表示切是错的”，“带这么多+早就加到 beta 了，你懂段位吗” 云云，学会更多名词和技巧是为了让自己理解社区其他人在表达什么以及友好的交流，而不是彰显自己多么懂键型，多么懂段位。
