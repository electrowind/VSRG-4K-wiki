# 基本常识

## 1. 米 / single note / rice / RC / 点 / 圆圈 <sup>[1]</sup>

<div style="text-align: right;color: lightgray;"><i><sup>[1]</sup>圆圈为官方名称，在 mania 侧几乎无人使用，主要用于 standard 侧。</i></div>

&emsp;&emsp;普通的 note。

## 2. 面 / long note / LN / 滑条 <sup>[2]</sup>
<div style="text-align: right;color: lightgray;"><i><sup>[2]</sup>同[1]。</i></div>

&emsp;&emsp;需要长按的 note，由面头，面身，面尾组成，面头需要**点击**，面身需要**长按**，面尾需要**松开手**。现代很多皮肤面尾面积远远小于面头。

## 3. 押 / chord 
&emsp;&emsp;一行所含的键数，1-6 键分别称为单押 / single、双押 / double / jump、三押 / triple / hand、四押 / quad、五押 / quintuple、六押 / sex<sup>[3]</sup>，当一行轨道均有键时称为**全押**，除单押以外的押又称为**多押**。现代 4K 下落式音游 / Vertical Scrolling Rhythm Game / VSRG 起源是舞蹈革命 / dance dance revolution / DDR，它是用脚游玩的游戏，当一行出现两个 note 时需要两只脚同时按压，即 jump / 跳，出现三个 note 时就需要手了，即 hand，quad 则正好代表“四”。

<div style="text-align: right;color: lightgray;"><i><sup>[3]</sup>就是 sex，不是 six，和 sextet / 六重奏类似。</i></div>

## 4. BPM / beat per minute / 每分钟节拍数 / 每分钟拍子数
&emsp;&emsp;一分钟之内的段落数量，一般该数值越高，音乐节奏越快。两根白线之间即为一个段落，称之为拍 / beat。

## 5. 谱面 / map / chart / beatmap
&emsp;&emsp;1-N 轨统称轨 / 轨道。<br />
&emsp;&emsp;白节拍线为 1 / 1（整拍），红节拍线为 1 / 2（半拍），蓝节拍线为 1 / 4（四分之一拍），除白节拍线外其他只能在编辑 / edit 界面看见；详情可见[谱面编辑器/音符时值 (Beat Snap Divisor) · wiki | osu!](https://osu.ppy.sh/wiki/zh/Client/Beatmap_editor/Beat_snap_divisor)
<br />
&emsp;&emsp;Note 下落到判定线周围一定范围时即可正确打击，偏移越远，得到的 acc越低，这遵循一定梯度，通常需要一定练习才能掌握正确时机，该范围称为判定区间。
