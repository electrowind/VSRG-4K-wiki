# 星数 / star rate / SR

Osu 使用的一种系统，现行版本中，密度对星数的影响远大于排列对星数的影响。
Sunny-rework 算法对于难度和星级的对应更加合理，是目前所有下落式音游系统定级系统最准确<sup>[1]</sup>、最全面<sup>[2]</sup>的算法。
<div style="text-align: right;color: lightgray;"><i><sup>[1]</sup> Etterna 现行版本对于 chordjack 键型定级偏低；Malody 的算法只和平均密度有关。
 </i></div>
<div style="text-align: right;color: lightgray;"><i> <sup>[2]</sup> Etterna 无法计算面条难度。
</i></div>
