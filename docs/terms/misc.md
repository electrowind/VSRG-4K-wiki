# 社区俚语（六）：Overclear、7+1K、PC 与 PE、彩率、Farm、Choke、转谱

## 1. Overclear

&emsp;&emsp;高于过段条件 1% 以上的成绩，如 RF 段为 96%，则 97% 以上的成绩为 overclear。

## 2. 7+1K

&emsp;&emsp;采用在 7K 的一侧加上一个仅由少量 note 下落的轨道来模拟 Beatmania IIDX 的碟，该轨道通常押歌曲中的重音。

&emsp;&emsp;详情可见 [Beatmania IIDX - 萌娘百科](https://mzh.moegirl.org.cn/Beatmania_IIDX)。

## 3. PC / person computer / 个人计算机，PE / pocket edition / 便携设备

&emsp;&emsp;在常见语境，PC 指台式机，笔记本电脑等，PE 指手机，平板电脑<sup>[1]</sup>等。

&emsp;&emsp;主要用于 Malody，因为在 Malody V 问世前的版本，PC 和 PE 端的判定区间有差异。

<div style="text-align: right;color: lightgray;"><i><sup>[1]</sup> 平板电脑 / 便携式电脑 / tablet personal computer，但绝大多数平板使用体验更接近手机。</i></div>

## 4. 彩率 / rate / ratio，反彩，抓彩

&emsp;&emsp;彩和黄的比率，又叫黄彩，彩黄等，是 osu 社区独有的称；GM 比，即 good 和 miss 的比率，在 osu 为绿和 miss 的比率，常<sup>[1]</sup>出现于极高准度的成绩。

&emsp;&emsp;彩率低于 1.0 时称为**反彩**，常出现于低准度或 SV1 下的高难面图成绩。

&emsp;&emsp;特意提高彩率称为**抓彩**，以及衍生出的一些特殊玩法，如抓黄，抓绿等。

&emsp;&emsp;彩率在鉴挂中的用法见[鉴挂 / cheat check](/VSRG-4K-wiki/playing/cheat-check/)。

<div style="text-align: right;color: lightgray;"><i><sup>[1]</sup> 本节的使用的"常"均为正常情况，与鉴挂的非正常情况不同。</i></div>

## 5. Farm

&emsp;&emsp;就像收菜一样收 PP，指某图很水或是在一段时间内刷大量的 PP。

## 6. Choke

&emsp;&emsp;差一点达到 XXacc 或 XX 评级等。如 96choke 表示差一点 96，S choke 表示差一点 S 评级。

## 7. 转谱 / convert

&emsp;&emsp;用工具或手动将一种谱面格式转为另一种谱面格式。

&emsp;&emsp;对于将 .msc 格式转为 .osu 格式的 bug 可以用以下方式解决：[关于转谱对齐流速的一点常用技巧](https://www.bilibili.com/opus/1088954937484771378)。
