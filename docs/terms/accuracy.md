# 社区俚语（三）：Acc 定级法、卖弱、神秘数字、KPS

## 1. Acc 定级法 / acc 计算法

&emsp;&emsp;已知某图的难度，用游玩不同图的 acc 做为标准来判断其他图的难度；该方法正常情况有一定参考性，但不够科学。

&emsp;&emsp;如 X 图准度为 96%，已知其难度为 7dan，Y 图打了 96.5%，Z 图打了 95.5%，断定 Y 图为 7-，Z 图为 7+。

## 2. 卖弱

&emsp;&emsp;能力较强的人在能力较弱的人面前表现出自己很弱。

&emsp;&emsp;如"我的一辈子"，"已经比我强了"等，不提倡学习。

## 3. 神秘数字

&emsp;&emsp;即 96.38，在 Kanemining 96.38% clear zeta dan 后该数字被发现经常出现在高难成绩图上。

## 4. KPS / keys per second

&emsp;&emsp;每秒键盘打击次数，平均水平为 6.69；CPS / clicks per second 是每秒鼠标点击次数；NPS / note per second 是每秒按键下落数量。
