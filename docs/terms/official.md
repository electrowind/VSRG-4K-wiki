# 官方名词 / official term

## 1. 概述

&emsp;&emsp;大部分官方名词，如判定严度 / overall difficulty / OD、掉血速度 / health / HP、不稳定率 / unstable rate / UR 以及各类 mod、各种成就，在 wiki 均可找到，并且有如何查看这些参数的图文教程，在此仅做部分介绍。

## 2. 稳定版 / stable / stb

&emsp;&emsp;目前较多人使用的版本，一般情况下对配置要求低，稳定性高于其他版本，现已没有大版本更新，在玩家完全转移到 lazer 前还会进行维护。

## 3. Lazer / lzr

&emsp;&emsp;未来将取代 stb 的版本，有非常多 stb 没有的功能，如自定义倍速等，但目前也有部分 stb 的功能未移植到 lzr。

&emsp;&emsp;stb 和 lzr 对比以及一些常见问题见[帮助中心 / 升级到 lazer · wiki | osu!](https://osu.ppy.sh/wiki/zh/Help_centre/Upgrading_to_lazer)。
