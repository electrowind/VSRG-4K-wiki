# 社区俚语（二）：段落、比、藏、热手、龙、和解

## 1. 水段，高潮段，休息段，尾杀

&emsp;&emsp;水段指一首歌相对简单的段落，高潮段则相反；高潮段有时根据水段对谱面的分割直接称为第一段、第二段等。

&emsp;&emsp;休息段指没有 note 或难度远低于高潮段的段落，并且夹在两个密度较高段之间。

&emsp;&emsp;尾杀狭义指歌曲最后一段，并且是整首歌的最难段；广义指歌曲最后一段，难度与最难段大致持平即可；含有三段高潮段歌曲的中间一段叫作中杀。

## 2. 比 / 逼 / b

&emsp;&emsp;擅长 XX 的人或群体，含轻微贬义或戏谑意味。

&emsp;&emsp;如：**叠比**，擅长叠键的人；**拍比**，擅长拍的人。

## 4. 热手 / warm up

&emsp;&emsp;音游玩家间隔一段时间没有游玩需要一段时间预热，这段时间叫作热手。

## 5. 龙，飞龙一般的

&emsp;&emsp;形容谱面非常难或玩家非常强，有一个说法是来自 SDVX 的暴龙天，即 SDVX 的最高段位；另一说法是来自龙玉涛<sup>[1]</sup>。

&emsp;&emsp;"飞龙一般的"是来自 Arcaea F-1 剧情翻译问题，"对立像条飞龙一样往前移动"，后更正为"对立疯狂地冲向对方"，用法同上。
