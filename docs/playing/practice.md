# 练习谱 / practice beatmap

&emsp;&emsp;低密度<sup>[1]</sup>的切、乱适合练切速，jacky tech 和低密度的叠适合练叠速；低密度叠关键词常为 speedjack。

## 1. 谱师 / mapper / 麻婆

### 1.1 米图谱师

&emsp;&emsp;按照平均谱面难度降序排列。

- [Hinako](https://osu.ppy.sh/users/13747903)：常规键型包；有大量赛图。
- [Shoegazer](https://osu.ppy.sh/users/2520707)：主要为技巧和切换倍速包；早期部分技巧密度高一些，后期低；切换密度低；冲击段位技巧图可练习他的图<sup>[2]</sup>；有大量赛图。
- [Leo137](https://osu.ppy.sh/users/1177817)：主要为切换倍速包；2121 排列<sup>[3]</sup>发明人。
- [Xingyue](https://osu.ppy.sh/users/9614083)：高密度双押切和高密度大叠倍速包。
- [Fullerene](https://osu.ppy.sh/users/2531335)：主要为切换倍速包。
- [Lynessa](https://osu.ppy.sh/beatmapsets?m=3&nsfw=1&q=lynessa&s=any)：常规键型均有；切换和叠键图较多，密度较高；倍速包基本都是其他玩家上传的。
- [IcyWorld](https://osu.ppy.sh/beatmapsets?m=3&nsfw=1&q=icyworld&s=any)：高密度切换倍速包，夹大量对拍或乱键；小众技巧谱；生涯后期（2024-）的图比较有自己的特色。
- [Rachel](https://osu.ppy.sh/users/8369409)：高密度叠键、满叠、高密度切换、乱键包，也有单曲倍速包。
- [Ena](https://osu.ppy.sh/users/13799949)：主要为高密度叠键倍速包；有少量超高密度切换倍速包。
- [Jhown](https://osu.ppy.sh/users/14772488)：高密度叠键倍速包。
- [MintApril](https://osu.ppy.sh/beatmapsets?m=3&nsfw=1&q=mintapril&s=any)：常规键型均有。
- [Teradora](https://osu.ppy.sh/users/20040607)：常规键型均有；有倍速包。
- [Doshowz](https://osu.ppy.sh/users/5799435)：osu 官网传的谱面较少，请移步 Etterna。
- [underjoy](https://osu.ppy.sh/users/2235750)：常规均有；有切换、叠键倍速包。
- [Beajak](https://osu.ppy.sh/users/12696546)：超高密度切换倍速包，切换段位和 BPM 练习谱包；制作的切换休息段较少，倍速给的很足，在难度名标记了 handstream 便于查找<sup>[4]</sup>。
- [Glorionoly](https://osu.ppy.sh/users/8957029)：低密度切换，排列比较有自己的特色。
- [Oceanus](https://osu.ppy.sh/users/9164100)：高密度切换倍速包；BPM 练习谱包。
- [Evening](https://osu.ppy.sh/users/2193881)：技巧和切换倍速包；大部分切换夹乱键。
- [flashnias](https://osu.ppy.sh/users/10906301)：叠键 BPM 练习谱包。
- [ATTang](https://osu.ppy.sh/users/1089335)：高密度乱键；锚比较多，而且难度较高；大多数图都比较有自己的特色。
- [frolica](https://osu.ppy.sh/users/4324195)：常规键型和 vibro 均有；技巧图含大量子弹；有倍速包。
- [Ska](https://osu.ppy.sh/users/10313023)：技巧和乱键倍速包，少量图比较有自己的特色；有大量赛图。
- [lemonguy](https://osu.ppy.sh/users/4693052)：常规键型均有；切换密度较低；包括大量赛图；部分图比较有自己的特色。
- [Anto](https://osu.ppy.sh/users/11221825)：vibro（200BPM 以上）、高密度叠键（190BPM 左右）包。

<div style="text-align: right;color: lightgray;"><i><sup>[1]</sup> 为避免混淆，本节不使用轻切、大叠等词汇。<br /><sup>[2]</sup> 字母段五首技巧图都是他的。<br /><sup>[3]</sup> 4dan 切换和 7dan 切换谱师。<br /><sup>[4]</sup> 善用浏览器的 Ctrl+F 搜索功能。</i></div>

## 2. 专项练习谱包 / practice pack

&emsp;&emsp;本节使用的网站是[谱面列表 | osu!](https://osu.ppy.sh/beatmapsets?m=3&nsfw=1&s=any)。

### 2.1 段位练习谱<sup>[5]</sup>

&emsp;&emsp;注意星数是否正常，部分 beta 包和 alpha 包难度明显标注不正常。<br />
&emsp;&emsp;段位低于 10 dan 谱面较少，可以开启 HT mod 将高段位图包降到低段位，如 delta+HT≈9 dan。

<div style="text-align: right;color: lightgray;"><i><sup>[5]</sup> 实际难度与标注难度有一定差距属于正常范畴，测试者并不能完美测试出谱面难度。</i></div>
