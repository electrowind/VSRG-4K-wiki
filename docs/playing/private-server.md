# 私服 / private server

&emsp;&emsp;私服指由玩家开设的服务器，其数据与官服不互通，意味着任何数据都可由服主自行更改。<br />
&emsp;&emsp;相较于官服多的功能包括但不限于：免费私服 supporter，全服务器排行榜，指令免费查看官服排行榜，更多 ranked 图，段位认定，免费更改 ID，全 mod 上传成绩等；但具体某服务器支持以上哪些功能请移步[osu 私服的游玩以及相较于官服的优势_哔哩哔哩 bilibili](https://www.bilibili.com/video/BV1che7zREWQ/?spm_id_from=333.1387.upload.video_card.click&amp;vd_source=26f7d7e1e073b22c5d55bf35f8c8bb62)。<br />
&emsp;&emsp;缺点也很明显：随时可能停服，运营团队人数少导致的外挂比例较高，玩家数量少，服务器相较于官服可能好不到哪里去，甚至更差。
