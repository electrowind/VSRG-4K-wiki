## 1. 压腕 / wrist up

&emsp;&emsp;由打字姿势自然形成的姿势，也是大多数人的姿势。

## 2. 悬腕 / wrist down / 抬腕

&emsp;&emsp;手腕悬浮在上空，对耐力要求较高。

## 3. 悬腕和压腕优缺点对比

&emsp;&emsp;部分玩家打不同键型采用不同姿势。

| | 压腕 | 悬腕 |
|:-----:|:-----:|:-----:|
| 学习成本 | 低 | 高 |
| 发力 | 自然 | 累 |
| 切指排列 | 简单 | 困难 |
| 叠键排列 | 困难 | 简单 |
| 锚 / 纵排列 | 困难 | 简单 |
| 手背受伤 | 容易 | 不容易 |

## 4. 发力

&emsp;&emsp;发力和键盘摆放、手臂姿势、桌子高度、手指弯曲程度有关，找到适合自己，并且不易受伤的即可；一般双手靠的比较近适合打爆发，但具体距离和每个人肩宽有关，它们之间本无优劣之分，适合自己就好。<br />
&emsp;&emsp;如果无法确定自己的发力，建议先玩一些 rank 图熟悉发力。<br />
&emsp;&emsp;[十三年老音游人的 4key 发力建议（仅供参考）_游戏热门视频](https://www.bilibili.com/video/BV183JLzfEhG/?spm_id_from=333.788.recommend_more_video.0&amp;trackid=web_related_0.router-related-2206146-n6d7k.1762144824738.580&amp;vd_source=26f7d7e1e073b22c5d55bf35f8c8bb62)（仅针对移动端）<br />
&emsp;&emsp;对于 PC 端音游，我觉得首先要调整桌面的位置，大臂与竖直方向呈 30° 角，此时手肘的高度和桌面平行，我认为这个高度是比较合适的。<br />
&emsp;&emsp;以下介绍几种常见发力方式，名字都是我自己取的，很多发力其实都是这些发力的变种，如有的人手贴桌边的同时，键位较远。
