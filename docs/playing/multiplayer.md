# 多人游戏 / multiplayer / multi / MP

&emsp;&emsp;注意，MP 界面也可使用 Ctrl + O 呼出设置，不需要退出再更改皮肤或键位。

## 1. 常见指令

&emsp;&emsp;[osu!tourney / 比赛管理指令 · wiki | osu!](https://osu.ppy.sh/wiki/zh/osu!tournament_client/osu!tourney/Tournament_management_commands)<br />
&emsp;&emsp;**!mp host 玩家名称**：将房主转移到指定玩家。<br />
&emsp;&emsp;**!mp start (数字)**：在指定的时间（秒）后开始比赛，如果没有提供时间，则立即开始比赛；在 stb 可用于单人开启联机游玩<sup>[1]</sup>。

<div style="text-align: right;color: lightgray;"><i><sup>[1]</sup> Lzr 可以直接进行游戏。</i></div>
