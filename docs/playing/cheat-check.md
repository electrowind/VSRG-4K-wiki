# 鉴挂 / cheating check

&emsp;&emsp;存在与最近水平差距过大的成绩即可认为是可疑的，下面介绍几种分辨是否为外挂的方式。非正常人游玩的谱面一眼就能分辨，在此不做介绍。

## 2. UR 条 / unstable rate bar

&emsp;&emsp;对于极难谱面，没有人能够抓准度的谱面，可以根据 UR 条看出来是否开挂。对于简单的谱面，该方法可能失效。

## 3. 流速 / 下落速度

&emsp;&emsp;一般来说<sup>[1]</sup>，正常人的下落速度在 24 到 38 之间，作弊玩家通常会使用极低的下落速度，如 12 或 15。

<div style="text-align: right;color: lightgray;"><i><sup>[1]</sup> 部分玩家如<a href="https://osu.ppy.sh/users/20992774">正能量小伙</a>会使用极低的下落速度。</i></div>

## 4. 彩率 / rate / ratio

&emsp;&emsp;对于极难谱面，极高的彩率或高准度下的反彩<sup>[2]</sup>都是不正常的；对于简单的谱面，榜上一些抓彩高手都没有全彩的图，某人做到了全彩也是可疑的。

## 5. GM 比

&emsp;&emsp;极难谱面很少有反 GM 比的成绩，可以此为依据；简单谱面则无法适用。

## 6. 回放渲染

&emsp;&emsp;有的非常离谱的高连击低 acc 高难图是用全拍技巧打出来的，可以用回放渲染工具分析。
